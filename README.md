# Eurovision-Excel-Dashboard

## Overview

Analysis of 60+ years of Eurovision Song Contest (1957–2022) 
in Microsoft Excel. The workbook contains 1,359 records across 
51 countries, structured across 4 sheets: DataSet, Analysis, 
PivotTables, and Charts.

## Features

- 11 analytical questions answered with Excel formulas 
  (COUNTIF, AVERAGEIF, MAX, COUNTIFS)
- 5 Pivot Tables with Slicers (Country, Year, Type filters)
- 5 Charts: bar, horizontal bar, column
- Conditional formatting on Top 10 rankings

## Skills Demonstrated

- Excel Formulas (COUNTIF, AVERAGEIF, COUNTIFS, MAX)
- Pivot Tables & Slicers
- Data Visualization (Bar, Column, Horizontal Bar charts)
- Conditional Formatting
- Dashboard Layout & Design
## Key Findings 
* Points inflation is real: average score grew from ~10 (1950s) to ~180 (2020s)
* Ukraine finished in Top 5 eight times despite competing since 2003
* Salvador Sobral (Portugal, 2017) holds the all-time record with 758 points
* Western European "Big 5" dominate participation count but not average points
